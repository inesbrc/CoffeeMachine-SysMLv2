Coffee Machine SysML v2

Project Overview

This project was developed using CATIA Magic (Cameo) SysML v2 Community Edition as part of a university project in Business Intelligence & Artificial Intelligence. The objective is to model the structure and behavior of a capsule-based coffee machine, including coffee selection, sensor verification, error handling, and machine states.

Model Contents

The project includes several complementary diagrams:
- Coffee Machine: System architecture, including the water tank, pump, heating system, capsule holder, sensors, and control unit.
- Coffee Type Selection Flow: Selection between Ristretto (25 ml), Espresso (40 ml), and Lungo (110 ml), using conditional statements.
- Coffee Preparation Flow: Preparation process with parallel sensor checks, conditional logic, and error handling.
- Recheck Sensors: Repeated sensor verification and variable updates.
- Coffee Machine States: Representation of the machine's different operating states.

Key Features 

- Conditional statements (if)
- Iterative loops (while)
- Parallel actions (fork and join)
- Variables, attributes, and assignments
- Boolean conditions and SysML v2 textual expressions
- System architecture and state modeling

How to Open the Model

1. Install a compatible version of CATIA Magic / Cameo with SysML v2 support.
2. Download CoffeeMachine-SysMLv2.mdszip from this repository.
3. Open Cameo.
4. Select File → Open Project.
5. Choose the downloaded .mdszip file.

Model Verification

The model was checked using the available SysML v2 textual validation features, with no errors reported during the final check. A complete behavioral simulation was not performed.
